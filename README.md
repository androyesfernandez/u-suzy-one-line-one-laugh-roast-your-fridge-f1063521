This program writes one original one-line roast of the fridge to `/output/entry.txt`. The line is a single sentence, 180 characters, with no line breaks — a Sunday-morning doctor's round through a vegetable drawer that has quietly become a hospice.

## Run

Requires Node 22. No dependencies, no network.

```sh
node main.ts
```

The entry line is written to `/output/entry.txt`.
